# Dashboard Project

لوحة تحكم حديثة تم تطويرها باستخدام React مع التركيز على بناء واجهات قابلة للتوسع والصيانة وفق أفضل الممارسات في تطوير الواجهات الأمامية.

## نبذة عن المشروع

يهدف هذا المشروع إلى محاكاة لوحة تحكم حقيقية يمكن استخدامها لإدارة البيانات والمحتوى داخل الأنظمة الإدارية. تم تطوير المشروع باستخدام هيكلية منظمة تعتمد على إعادة استخدام المكونات (Reusable Components) وفصل المسؤوليات لتحسين قابلية التطوير والصيانة مستقبلاً.

## المميزات

* دعم اللغتين العربية والإنجليزية.
* التبديل بين الوضع الليلي والوضع النهاري.
* حفظ الإعدادات داخل Local Storage.
* تصميم متجاوب يعمل على مختلف الأجهزة.
* Reusable Components.
* Custom Hooks.
* Context API لإدارة الحالة العامة للتطبيق.
* تنظيم احترافي للمجلدات والملفات.
* واجهة مستخدم حديثة وسهلة الاستخدام.
* بنية قابلة للتوسع وإضافة مزايا جديدة بسهولة.

# Dashboard Project

A modern dashboard application built with React, focusing on scalability, maintainability, and reusable architecture following modern frontend development practices.

## Overview

This project simulates a real-world dashboard system that can be used for managing data and administrative operations. The application is structured using reusable components and clean architecture principles to ensure long-term maintainability and scalability.

## Features

* Arabic and English language support.
* Dark Mode and Light Mode.
* Persistent settings using Local Storage.
* Responsive design across multiple devices.
* Reusable Components.
* Custom React Hooks.
* Context API for state management.
* Clean and scalable folder structure.
* Modern and user-friendly UI.
* Easily extendable architecture.

## Technologies Used

* React
* JavaScript (ES6+)
* Context API
* Custom Hooks
* CSS
* Local Storage
* Vite

## Project Architecture

The project follows a modular architecture based on:

* Components
* Context Providers
* Custom Hooks
* Shared Utilities
* Reusable UI Elements

This structure improves maintainability and simplifies future development.
